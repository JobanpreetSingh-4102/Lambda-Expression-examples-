# Lambda Expressions in Java

A simple Java project demonstrating **Lambda Expressions**, **Functional Interfaces**, and the **Stream API** introduced in Java 8.

## 📚 Topics Covered

- Introduction to Lambda Expressions
- Anonymous Inner Classes
- Lambda Syntax
- Functional Interfaces
- Built-in Functional Interfaces
- Lambda with Collections
- Stream API
- Method References


##🎯 Learning Outcomes

- Write concise Java code using Lambdas
- Understand Functional Interfaces
- Use Stream API for data processing
- Improve code readability and maintainability
